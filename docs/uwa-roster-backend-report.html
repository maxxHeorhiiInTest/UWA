Як зараз зберігаються зміни і що зміниться на бойовому домені

Короткий опис бекенду адмінки для команди. Зараз сайт живе на Vercel без окремої бази. На реальному домені ростер має піти в MongoDB (або аналог). Звіт фіксує обидва етапи і що між ними не ламається.

Як працює зараз

Потік збереження

  1. Редактор логіниться на /admin/login. Сервер звіряє логін і пароль з env і ставить httpOnly-куку uwa_admin.
  2. Форма картки йде Server Action. Сервер ще раз перевіряє підпис куки (AUTH_SECRET). Без сесії правки не пишуться.
  3. З форми збирається повна картка: імена UA/EN, категорія, біо, титули, матчі, відео, суперництва, фото.
  4. Читається весь ростер, картка замінюється або додається, JSON пишеться в Blob двічі: нова версія і data/roster.json.
  5. Скидається кеш /ua/roster, /en/roster і адмінки. У UI — попап «Збережено».

Чому саме так

На Vercel немає постійного диска. Файл у репозиторії після деплою тільки для читання, тому живі правки йдуть у Blob.

Весь ростер — один JSON. Це просто і достатньо, поки редактор один і карток десятки, не тисячі.

Версійні файли потрібні тому, що перезапис публічного Blob може віддавати старий JSON до ~60 секунд. Новий pathname одразу свіжий.

Медіа окремо від карток

Фото їдуть разом із формою (ліміт тіла ~10 МБ). Відео до 80 МБ грузиться з браузера в Blob, у JSON лише посилання. YouTube / Vimeo — тільки URL, без файлу.

Як буде на реальному домені

Домен (наприклад uwa.ua) вішається на той самий Vercel-проєкт. Адмінка і публічні сторінки лишаються. Міняється шар даних карток: замість JSON у Blob — MongoDB Atlas (або Postgres / аналог).

Не чіпаємо

  • /admin, форми карток, попап збереження
  • Публічний ростер /ua і /en, картки, плеєр відео
  • Кука адміна або той самий логін на старті
  • Blob для фото і відеофайлів (або пізніше окремий CDN)
  • Server Actions як єдиний вхід з форми

Новий шар даних

  • getWrestlers / saveWrestler ходять у Mongo, не в Blob JSON
  • Одна картка = один документ, без перезапису всього списку
  • MONGODB_URI в Vercel Production; кластер окремо від фронту
  • Бекапи і індекси на стороні Atlas
  • Кука прив’язана до бойового домену; логін з vercel.app туди не переїде

Цільовий потік

Браузер (https://домен/admin) → Server Action → перевірка сесії → MongoDB (insert / update картки) → invalidate кешу ростера → попап «Збережено».

Публічна сторінка → getWrestlers() → find() по колекції → той самий UI ростера.

Файл відео як і зараз: браузер → /api/admin/video → Blob → URL у документі картки.
